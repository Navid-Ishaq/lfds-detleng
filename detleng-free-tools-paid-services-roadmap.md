# DeTLeng Free Tools → Paid Services Roadmap

## Purpose

This is the master implementation roadmap for building useful public tools across the DeTLeng ecosystem.

> **Free Tool → Small Problem Solved → Bigger Problem Revealed → Consultation → Paid Project → Monthly Care**

The tools should be genuinely useful. Promotion should come naturally after the user receives value.

---

# Core Principle

## Useful first. Promotional second.

For every tool, define:

1. What small problem does it solve for free?
2. What bigger problem might still remain?
3. Which DeTLeng service can solve that bigger problem?
4. What is the natural CTA after the tool has done its job?

Do not lead with technology. Lead with the real work.

# Final Philosophy

Do not build free tools only because they are easy to code.

Build tools that sit close to real problems.

The best public utilities should do three things:

1. Genuinely help someone.
2. Demonstrate DeTLeng capability without boasting.
3. Naturally reveal a bigger problem DeTLeng can solve.

## The customer does not buy Python.

## The customer does not buy AI.

## The customer does not buy an API.

# The customer buys something working better.
