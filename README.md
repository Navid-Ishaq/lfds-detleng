# LFDS — Logic First Digital Solutions

Official static website for [lfds.detleng.com](https://lfds.detleng.com/).

LFDS starts with the problem, chooses technology only when it helps, and builds practical solutions using better processes, websites, automation, AI, data, and custom digital tools.

The site also provides a focused route into Naveed's automation work: Automation Desk, n8n DeTLeng, DeTLeng n8n Lab, DeTLeng Ops, and Speaking n8n. DeTLeng Network remains the separate directory for the wider ecosystem.

## Files

- `index.html` — complete responsive website
- `assets/favicon.svg` — LFDS brand favicon
- `CNAME` — GitHub Pages custom-domain configuration

No build step or external dependency is required.
